# Benchmark index

- `__init__.py` — Exports benchmark runner, experiment presets, and report classes.
- `experiments.py` — Defines standard, ablation, and quick benchmark experiment sets.
- `reports.py` — Formats benchmark results as structured reports.
- `runner.py` — Runs configured experiments and records metric results.
- `index.md` — Index of benchmark setup, execution, and reporting modules.
